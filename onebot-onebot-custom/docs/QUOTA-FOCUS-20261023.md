# AGY 额度回复

群聊由入站模型判断query/refresh，固定执行器取数并筛选。随后把完整的安全事实数据交给当前聊天模型和角色的隔离rewrite helper，一次生成整条最终回复。发送的是该模型的完整候选，程序不拼接引导语或配额明细，也不把原始格式化数据当作最终成功回复。

仅关注gemini-3.1-flash-image、gemini-3.8-flash-high、claude-opus-5-5-low的5小时与周配额及北京时间重置时间。Gemini两项共享gemini-5h/gemini-weekly桶，Claude使用3p-5h/3p-weekly桶。模型级percentage不是独立窗口，缺少桶时显示未知。百分比保留最多两位小数，避免不足1%的周配额被舍入成0%。

程序校验模型标识、配额窗口、百分比、重置时间及未知/缓存/刷新失败状态，不修改生成的正文。校验失败重写一次，仍失败则请模型完整生成简短失败说明；没有有效模型输出时仅记录失败，不回传未经校验的额度总结。单次生成使用modelReplyTimeoutMs（180秒）。取消后不重试、不发送迟到回复。普通访客继续沿用昵称/中性称谓限制。

私聊quota_query/quota_refresh工具复用同一数据筛选器，工具返回replyInstruction，最终整条答复由原聊天模型根据人设生成。入站quota意图及agy-proxy技能也要求同一数据范围，以涵盖管理员直接使用固定诊断脚本的路径。权限及固定脚本执行边界不变。

验证范围：固定执行器、窗口精度/缺失、多账户隔离、刷新状态、秘密过滤、完整模型候选原样发送、错误事实校验及重生成、取消、全失败时不拼接事实，以及业务工具输出筛选。真实本机quota只读查询通过，测试不向QQ发送消息。

真实接口验收：当前主链路曾返回账号池限流503，因此按现有errorFallbacks顺序尝试备用模型；整条模型回复在34.270秒完成，一次事实校验通过，没有拼接、没有发送QQ测试消息。所有生成/重写/备用尝试共用200秒外层预算，单次模型上限180秒。结构化记录见QUOTA-FULL-LLM-ACCEPTANCE-20261023.json。
